# 🚀 A-Pay Monetized Next.js 15 Agent App

A modern fullstack Next.js application equipped with **A-Pay HTTP 402 Micropayments** on Base Layer 2.

## ⚡ Quickstart

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   ```bash
   cp .env.example .env.local
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser.
