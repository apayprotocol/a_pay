# 🚀 A-Pay Monetized Express Service

A lightweight Node.js Express service protected by **`apay-gateway`** on Base Layer 2.

## ⚡ Quickstart

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   ```bash
   cp .env.example .env
   ```

3. Run server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser.
